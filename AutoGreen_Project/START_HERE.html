1. Project overview

AutoGreen turns a registration CSV into a clear, interactive dashboard. It helps users identify leading states, compare monthly patterns and understand changes between comparable periods. Python provides a reproducible analysis workflow; the white and green website makes the results easy to explore.

Research questions: Which states record the most registrations? How do counts change each month? How does January–September 2026 compare with the same months in 2025? Where are data incomplete?

3. Methodology

  1. Load the original CSV and inspect its columns and date coverage.
  2. Validate numeric values and unique state-month keys.
  3. Preserve missing values and identify incomplete records.
  4. Aggregate reported counts by month, year and state.
  5. Join state-month records across years for comparable growth.
  6. Create charts, summary CSVs and the interactive dashboard.
  7. Run regression checks and explain limitations.
Growth = (matched 2026 total − matched 2025 total) ÷ matched 2025 total × 100. Only pairs with reported values in both years are included.

5. Dashboard features

The included dashboard provides Overview, Analysis studio, state comparisons, monthly heatmaps, data-quality checks and a searchable record explorer. Users can select years, states and periods, inspect exact chart values and export CSV results. Comparison controls and raw-table controls are labelled with their scope.

6. Validation

All six Python regression checks passed: coverage, preserved missing counts, total reconciliation, matched-pair growth, unreported future months and sparse-state matching. The included dashboard version was previously tested for filters, searches, year changes, pagination and downloads. Notebook Python cells were executed sequentially and saved with results and charts; an interactive Jupyter kernel was not used during packaging.

7. Limitations

  • Only 2025 and January–September 2026 are available.
  • Source values have not been independently verified.
  • Five unknown counts are not treated as zeros.
  • Manufacturer, model, segment, price and buyer fields are absent.
  • High percentage growth from a small base should be read with absolute counts.
  • Descriptive patterns do not establish causes.

8. Future development

Acquire five years of consistent monthly manufacturer/state registrations and document category definitions and company mappings. Add company comparisons once supported by real data. Forecasting is optional later: compare a simple baseline with a candidate model using a chronological holdout and error metrics. The current project contains no trained predictive model.

9. How to demonstrate

Open the README for setup. Start the dashboard with python -m http.server 8000 --directory dashboard, then visit http://localhost:8000. Demonstrate Overview → Analysis → Compare States → Heatmap → Data Quality. Open the notebook to explain how the numbers were produced.

10. Conclusion

AutoGreen provides a reproducible way to inspect regional registration patterns while making data gaps and coverage differences visible. The project combines Python exploratory analysis with an interactive website and documents the boundaries of what the available data can answer.
