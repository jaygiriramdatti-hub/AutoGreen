BEHIND THE NUMBERS

A mini project with a clear purpose.

Explore regional demand patterns using descriptive data analysis. Filter the dataset, inspect monthly trends and compare states using the same months in each year.

Dataset & methodology

756 rows · 36 states / UTs · 2025–2026. Uploaded CSV sourced from Tamil Nadu Data ↗. Source metadata is retained; figures have not been independently verified.

Missing values remain missing. Totals sum reported values only. Growth uses only state-month pairs reported in both years. 2025 growth is unavailable because 2024 is not provided. This is a static snapshot, not a live feed.
